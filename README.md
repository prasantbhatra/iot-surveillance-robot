# 🤖 IoT Surveillance Robot

> Smart Security Robot with Raspberry Pi, Python, Live Streaming & Sensor Alerts

### 📌 Overview
Built an autonomous IoT surveillance robot for real-time monitoring and intrusion detection. The robot streams live video, processes PIR & ultrasonic sensor data, and sends alerts via IoT.

### 🛠️ Tech Stack
- **Hardware:** Raspberry Pi 4, PIR Sensor, Ultrasonic HC-SR04, Pi Camera, Motor Driver L298N
- **Software:** Python, OpenCV, Flask, MQTT, IoT Cloud
- **Features:** Live video streaming, Motion detection, Obstacle avoidance, Remote control via web app

### 🚀 Key Features
- ✅ Real-time surveillance with live camera feed
- ✅ Motion detection & alert system
- ✅ Autonomous navigation & obstacle avoidance
- ✅ IoT dashboard for remote monitoring

### 💻 Code Structure
- `sensor_alert.py` - PIR motion detection logic
- `robot_control.py` - Motor control & navigation
- `app.py` - Flask live stream server
